# ADR-0150：无人值守采集不创建浏览器窗口

- 状态：Accepted
- 日期：2026-11-02
- 修订：ADR-0065 的屏幕外窗口和人工点击回退。

## 背景

后台采集会持续遇到验证页。屏幕外坐标不能保证窗口隐藏，macOS 会调整窗口位置；验证超时后的
`Page.bringToFront` 还会打断正在使用电脑的人。无人值守任务应持续处理队列，不依赖人工处理浏览器窗口。

## 决策

采集使用 `--headless=new`，沿用独立 profile、来源连接方式和 CDP 导航取页。
自动等待和一次清理该站 cookie 后重载仍未通过验证时，清空验证页并报 `ChallengeUnsolved`，
由现有来源冷却机制处理，继续后续来源与任务。取消人工点击等待及其提醒状态。

`_Browser.place` 只接受 `attended=True` 的窗口操作。主动发起的 PikPak 浏览器登录保留可操作窗口，
无人值守采集在启动、重试、失败和恢复后均不得切换前台。

## 后果

采集无需桌面窗口，也不会为等待点击占用额外两分钟。部分来源可能拒绝无窗口浏览器，
此时资料获取会失败并冷却；不保证所有站点可用，也不切换成可见窗口重试。
无需迁移数据，重启服务即可对后续请求生效。保留既有平台浏览器发现规则，不扩大平台支持范围。
